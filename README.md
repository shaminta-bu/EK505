# EK 505 Workspace

This workspace is organized for the EK 505 course.

## Structure
- `course-info/` – syllabus, course details, and instructor information
- `notes/` – lecture notes, summaries, and class takeaways
- `assignments/` – homework, labs, and deliverables
- `exams/` – quizzes, tests, and review materials
- `resources/` – readings, references, and useful links
- `projects/` – course projects and implementation work
- `templates/` – report, assignment, or project templates

## Suggested use
1. Add lecture notes to `notes/` after each class.
2. Save all homework and submissions in `assignments/`.
3. Keep course materials and reference links in `resources/`.
4. Store code or project files in `projects/`.
5. Use `calendar.md` and `todo.md` to track deadlines and tasks.
